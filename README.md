# CHLAZENÍ servis

Vícestránkový český web pro CHLAZENÍ servis s.r.o. – Opava a Moravskoslezský kraj.

## Nasazení
Vercel: Framework Other, build `node build.mjs`, output `dist`, bez závislostí.

## Funkce
Samostatné stránky, výběr servis/projekt, kontakty podle oboru, galerie s ovládáním klávesnicí, příprava e-mailu a kopírování zprávy. Formulář sám zprávy neodesílá; otevře e-mailový program.

## Podklady
Logo, fotografie realizací a kontakty převzaty z https://www.chlazeniservis.cz/. Fotografie nejsou generované. Písma Barlow Condensed a IBM Plex Sans jsou uložena lokálně.
